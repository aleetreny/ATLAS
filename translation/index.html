Module 3.1 · Adversarial · Translation

The two previous articles asked for a picture out of noise. This one starts from a picture: a flat plan of a scene, to be turned into a render of it. Sketch to photograph, map to satellite, daylight to dusk, and the family of tasks nobody would have called generative modelling before 2016.


Starting from a picture changes two things at once, and they pull in opposite directions. There is now a right answer, so an ordinary regression loss is available and there is no need for any of the machinery in Counterfeit. And there is still not a unique right answer, because the plan does not say which windows are lit, so that regression loss is being asked a question it can only answer with a summary of every answer that was possible.

Blur Is The Correct Answer

Measured below.

One plan, one pixel

Take a single plan and a single pixel inside one of its windows. The plan fixes where the window is. It says nothing about whether the light is on.

Rendered again and again

The same plan, rendered many times. This is the distribution of that one pixel, and it is not a bell around a middle: it is two lumps.

Because a window is a switch

Lit or unlit, nothing in between. Every render in the dataset puts that pixel at one end or the other, and the middle is a brightness the data never contains.

And the two losses miss differently

A squared-error loss is minimised by the mean, which lands in the empty middle: that is the grey window everybody has in mind. An absolute-error loss, which is the one pix2pix uses, is minimised by the median, which snaps to whichever state was commoner: sharp, confident, and wrong about the rest. Neither is failing. Both are answering exactly what was asked.

The Verdict

What each idea on this page is worth, at this scale, on these scenes.

Idea What it buys Measured here Watch out for
A regression loss Fidelity: the output lands where the answer is, without a second network to argue with Measured above. It returns a summary of every answer that was possible, which is the right answer to the wrong question wherever the mapping is one to many.
An adversarial term Commitment: outputs that belong to the distribution rather than to its middle Measured above. It has no idea which of the possible answers is the right one, so on its own it will produce a perfectly plausible render of a different scene.
A patch discriminator A critic that judges texture locally, with far fewer weights than one that judges the whole image Measured above. The patch size everyone quotes is the window of the convolutions. Put a normalisation layer inside and its statistics pool over the whole image, so the real window is everything.
Cycle consistency A way to train a translator with no paired examples at all Measured above. Invertibility does not single out the correspondence you wanted. Any relabelling that is undoable scores the same, and the round trip can be carried by a signal too small to see.
