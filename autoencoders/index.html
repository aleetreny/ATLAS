Module 2.2 · Dimensionality Reduction · Learned Compression

Five methods so far, and one thing none of them does. PCA, classical and non-metric scaling, Isomap, locally linear embedding, t-SNE and UMAP all produce coordinates by solving for them: an eigenproblem, a stress, a graph, a divergence. When the solve is finished the coordinates exist and nothing else does.


That has two consequences that only show up when you try to use one. Hand it a new row and there is nowhere to put it: PCA can project, because a projection is a matrix, but for t-SNE and Isomap the honest answer is to run the whole fit again with the new row in it, at which point every old coordinate has moved too. And go the other way, from two coordinates back to a row, and there is no way at all.

Written down it is two functions and one loss, and the only structural requirement is that \(k\) is smaller than \(p\):

$$ z = f_{\theta}(x) \in \mathbb{R}^{k}, \qquad \hat{x} = g_{\phi}(z) \in \mathbb{R}^{p}, \qquad k \ll p $$ $$ \min_{\theta, \phi}\; \tfrac{1}{n}\textstyle\sum_i \lVert x_i - g_{\phi}(f_{\theta}(x_i)) \rVert^2 $$
