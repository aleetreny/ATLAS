One Step Of Memory

A hidden Markov model makes two assumptions, and both of them are wrong on purpose.

$$P(w_{1:n}, t_{1:n}) = \prod_{i=1}^{n} P(t_i \mid t_{i-1})\, P(w_i \mid t_i)$$

Every tag depends on exactly one tag, and every word depends on exactly one tag. Nothing else.

The Verdict

Four models of memory, one task with an answer key, and one synthetic task built to break them.

Reach for When What it bought here Watch out for
Most frequent tag Before writing any model at all Measured above. It has no answer for a word it never saw.
Hidden Markov model The label sequence has strong local structure and you want the whole model to fit in a table Measured above. One step of memory, by construction.
Plain RNN Rarely Measured above. Its memory has a measured half life.
LSTM or GRU The answer depends on something that happened a while ago Measured above. Still one token at a time, forever.
