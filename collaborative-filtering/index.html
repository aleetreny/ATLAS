Module 6.1 · Recommenders · Collaborative Filtering

Every model in this atlas so far has been handed a description of the thing it is reasoning about. A row of numbers, a picture, a sentence, a waveform: something intrinsic to the object. This module changes the object. Here an item has no description at all, and what stands in for one is the list of people who touched it.
