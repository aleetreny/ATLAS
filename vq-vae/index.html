A Finite Alphabet

A continuous code has no natural size, so its rate had to be estimated in nats through a divergence; make the code a symbol from a fixed list and the rate becomes a count of bits, at the price of a gradient that does not exist

aleetreny

Module 3.2 · Probabilistic Generative Models · Discrete Codes

The previous article measured a code's rate in nats, as a divergence between two continuous distributions, because a real number has no size. Two numbers of latent could carry six nats or eighty depending on how tightly the second term squeezed them, and the only way to know was to compute a KL.


Replace the code with an entry in a fixed list and that stops being true. Four cells, sixty four entries each, is twenty four bits: not an estimate, a count. Everything else in the model stays where it was, and the whole article is about what changes when the code becomes a symbol.
